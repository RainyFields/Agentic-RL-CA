numbers. Rebuild: `cd assets && python3 extract_metrics.py && python3 build_figures.py &&
python3 build_f8a.py && python3 build_taxonomy.py` (writes both `.png` and `.pdf` here).

## Backing tables

- **`finals.csv`** — generated by `build_figures.py`; one row per seeded run = the FINAL (@500)
  val-2048 macro-EM, response-length clip ratio, and avg turns, read straight from the step-500 row
  of each `csv/<run>.csv`. This is the bar-chart source and the primary-comparison table.
- **`csv/<run>.csv`** — per-run training history (step, val_macro_em, reward_mean, avg_turns,
  clip_ratio, success_rate), produced by `extract_metrics.py` from
  `~/xiaoxuan/worker_logs/launches/*.log` (last-occurrence-per-step; pre-hang + post-hang-relaunch
  logs merged in chronological order — see the `RUNS` dict for the exact log list per run).

## Notes

- Metric = **val_2048 macro-EM** (fixed 2,048-question stratified subset, greedy, every 25 steps),
  the pre-registered training-time proxy for the full 51,713-question paper metric. token-GRPO s0's
  full-set macro-EM (0.3951) sits within ≈0.006 of its val_2048 @500 (0.389), validating the proxy.
- The FINAL@500 checkpoint is the pre-registered primary comparison for every arm (best-val is
  reported in the decision log but is never the headline).
