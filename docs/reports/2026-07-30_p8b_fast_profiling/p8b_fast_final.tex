\section*{4. Entropy-metric flag: resolution}
\flag{Resolved as measurement artifact --- logically conclusive.} The 2$\times$ gap
(fast 1.05 vs baseline 2.07) appears at \textbf{step 1, before any parameter update}: both
runs generate rollouts with \emph{identical weights, data order and sampling config}, so a
true policy-entropy difference is impossible; only the \emph{metric computation} differs.
The \code{actor/entropy\_loss} metric is produced during the old\_log\_prob pass and
averaged over micro-batches; token-budget packing changes micro-batch composition (few
large heterogeneous packs vs many fixed-size ones), reweighting the average. Behavioral
statistics agree throughout (success 0.20 vs 0.20, response length 493 vs 501, episode
turns 4.66 vs 4.56, val@0 identical at 0.195/0.199). The metric is \emph{not comparable
across packing modes} --- treat entropy trends within a run as valid, across configs as not.
