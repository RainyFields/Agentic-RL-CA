\section*{4. What \code{grpo\_fast} changes (and what it must not change)}
Baseline = \code{p8bprof\_grpo\_partial} (same data, seed 0, 256$\times$5, 4 cycles, partial
args \code{cycle\_turns=8}/\code{max\_age=4}). Deltas --- all \textbf{throughput-only}, gradient
math untouched:
\begin{enumerate}
\item \textbf{Dynamic token-budget micro-batching} (\code{DYNBSZ=1}): \code{use\_dynamic\_bsz=True}
at 24{,}576 tok/GPU for actor update, old\_log\_prob and ref forwards (critic keys wired for
gae arms). Replaces fixed \code{MICRO\_BSZ=1} ($\sim$5.2k real tokens/forward). Same minibatch
partition (\code{ppo\_mini\_batch\_size=512}); packing only regroups forwards.
\item \textbf{Chunked prefill} + \code{max\_num\_batched\_tokens=17408} (fork requires
$\ge$\code{max\_model\_len}; user-requested 16384 rejected by validation).
\item Nothing else: template, KV 0.5, remove-padding, balance-batch, grad-ckpt, sampling,
all algorithm settings identical. OOM ladder: 24576 $\to$ 16384 $\to$ revert (separately named).
\end{enumerate}
\textbf{Early step-1 evidence} (04:59 CST): update 124.5\,s$\to$\textbf{51.4}\,s,
old\_log\_prob $\sim$500\,s-class$\to$\textbf{14.6}\,s, ref$\to$\textbf{17.1}\,s at matched
released count (325); gen flat (587 vs 553\,s --- fresh short prompts; the chunked-prefill
test is cycle 2's deep resumed prompts); peak 77.9\,GB, no OOM. Known confound vs baseline:
baseline ran at KV 0.6, fast at 0.5.
