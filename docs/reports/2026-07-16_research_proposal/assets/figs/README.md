# Figure provenance

Every figure is generated by `../build_figures.py` from `../csv/<run>.csv`, which
`../extract_metrics.py` extracts from the raw launch logs (paths hardcoded in RUNS).

| figure | data | note |
|---|---|---|
| fig_learning_curves | val_macro_em column, all arms | val-2048, greedy, every 25 steps |
| fig_final_bars | final/latest val_macro_em per arm | GiGPO/token-PPO still training at snapshot |
| fig_reward_turns | reward_mean, avg_turns (seed-0 arms) | EMA-smoothed; B1/B1sh reward includes +0.2 step bonus |
| fig_tripwire | clip_ratio + late val_macro_em | response_length/clip_ratio from training logs |

Untrained baseline 0.2246 = val-before-train of the wave-0 run.
